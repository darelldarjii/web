# Website Seragam & Jadwal PT. Genesis Berkat Usaha

## Cara menjalankan
1. Extract ZIP.
2. Buka folder di VS Code.
3. Buka `index.html` di browser.

Tidak membutuhkan npm atau server khusus.

File:
- index.html
- style.css

Catatan:
Ikon menggunakan Font Awesome melalui CDN dan font menggunakan Google Fonts, sehingga koneksi internet diperlukan agar ikon/font tampil sempurna.
